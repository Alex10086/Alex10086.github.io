# 简介（~~蹩脚翻译~~）
 * #### 问题引入
>给定一个含$2^N$个整数的集合$A$，对于每一个$i$，$x$&$i$=$i$，即$i\in x$，我们需要计算$∀x$函数$F(x)$=$A[i]$的和。

>$$F[mask]=\sum_{i\in mask}\ A[i]$$

 * #### 前置知识

>基本的$DP$知识

>位掩码：使用二进制表示状态

 * #### 解决方法

>###### 暴力硬做

```cpp
for(int mask = 0;mask < (1<<N); ++mask)
		for(int i = 0;i < (1<<N); ++i)
			if((mask&i) == i) F[mask] += A[i];
```

>>喜提 $O(4^N)$

>###### 有点脑子

```cpp
for (int mask = 0; mask < (1<<n); mask++)
{
		F[mask] = A[0];
		for(int i = mask; i > 0; i = (i-1) & mask)
	      		F[mask] += A[i];
}
```

>>这样做相比前一种方法有一定的提升。对于每个状态，我们只枚举它的子集，若一种二进制状态中有$K$个$1$，那么它的子集就有$2^K$个，这样的状态有 $\begin{pmatrix}N\\K\\\end{pmatrix}$个，所以，总共的时间复杂度是
>  $$\sum_{K=0}^{N}\ \begin{pmatrix}N\\K\\\end{pmatrix}2^K =(1+2)^N=3^N$$
>PS:二项式定理

来自教练的奇妙证法：该种方法中每位有三种状态：由于K的限制枚举永远为$0$、$1$和$0$，一共有$N$位，所以是$3^N$。~~好像很有道理的亚子~~

>###### $SOS$ $DP$（译不动了）

# 例题
[CF1679E Typical Party in Dorm](https://www.luogu.com.cn/problem/CF1679E)

>题目大意：
>>给定有$n$个正整数的数列，对于每个数，求数列中一个数和他按位与后等于$0$，称为相容。

>按位与等于$0$就是说，每一位必须有$0$，对于每一个数，若这一位是$1$，另一个数必须是$0$，该位为$0$则随意。发现另一个数其实就是当前数按位取反后的子集。考虑预处理出每一个数的子集，再输出答案。

>[评测记录](https://www.luogu.com.cn/record/79040202)

[CF449D Jzzhu and Numbers](https://www.luogu.com.cn/problem/CF449D)
>题目大意：
>>给定$n$个数，求从这些数中选任意个按位与起来等于$0$的方案数。

>把这些数转化为二进制，考虑用容斥原理进行求解。总共方案是$2^n-1$个，考虑当规定减去某位与起来是$1$的方案数,加上某两位同时是$1$的方案数，减去某三位同时是$1$的方案数……。

>那么只需求出$1$~$10^6$中每个数按位取反后是给出的数按位取反后中多少个数的子集即可。

>[评测记录](https://www.luogu.com.cn/record/78723909)

[P6442 [COCI2011-2012#6]KOŠAR](https://www.luogu.com.cn/problem/CF449D)
>题目大意：
>>$n$个箱子，$k$种玩具，每个箱子都有几种玩具，求选任意个箱子，包含所有种类玩具的方案数。

>把玩具转化为二进制，有则$1$，无则$0$。发现我们想要的是某一位至少有$1$个$1$，也就是或起来为$11111111$……

>那么我们取个反，每一位必须有一个$0$，也就是与起来全部为$0$，不就$\approx$上一题吗 XD

>[评测记录](https://www.luogu.com.cn/record/78727055)

[CF1679E Typical Party in Dorm](https://www.luogu.com.cn/problem/CF1679E)

>题目大意：

>>给定一个长度为$n$的文本串，和$q$个模式串，均由前$17$个字母组成，文本串中含有$?$，它可以用模式串中任意字母替代，求对于每个模式串匹配文本串，能生成多少个不同的回文子串。

>考虑预处理，通过枚举回文中心与区间一步步拓展，分情况讨论：
>> * 若两个相同，且都是$?$，贡献就是模式串长度。
>> * 若两个相同，也不是$?$，贡献就是$1$。
>> * 若两个不同，一个是$?$，贡献就是另一个字母是否在模式串中。
>> * 若两个不同，也没有$?$，贡献就是$0$。

>最后还要考虑不在回文区间的$?$的贡献。

>### 但是 
> 强行枚举所有子集是$3^n$的复杂度，过不去，考虑优化。

>考虑多加一维$k$，保证枚举的字串$1$到$k$与整个模式串相同，可以预处理出来一些东西，无需枚举所有字串。时间复杂度降到$n2^n$级别，可以过。

>最后滚动一下就好了。
